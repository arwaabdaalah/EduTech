# EduTech

## 📚 About the project
EduTech is a full-stack educational platform designed to make it easier for students to discover, compare, and choose the best online courses from multiple providers in different fields.

The platform brings courses together in one place, allowing students to search for courses based on their interests and needs, explore course details, compare available options, and make informed decisions about what to learn.

EduTech also provides instructors with a dedicated platform to upload and manage their courses, track student enrollment and engagement, and monitor student feedback and reviews. This helps instructors understand their students' experiences and continuously improve the quality of their educational content.

The platform aims to connect students and instructors in one organized environment while making the process of finding, managing, and improving online learning more efficient.

## ⚠️ Problem
Students often have to search across different educational platforms to find suitable courses, which can make it difficult and time-consuming to compare different options and choose the right course.

At the same time, instructors need an easy way to publish their courses, manage their content, and understand student feedback.

## 💡 Solution 
EduTech provides:

- A centralized catalog of courses from multiple providers.
- Search and filtering to help students find relevant courses.
- Detailed course information to help students make better decisions.
- Instructor tools for uploading and managing courses.

## 📒 Main Features
- Authentication ➜ Helping the user to login and create a new account.
- Users ➜ The user profile and Dashboard contain information on their progress.
- Courses ➜ Search and filter to find the right course and view all its details.
- Assignments / Quizzes ➜ Find out the test results.
- Lessons and Chapters ➜ Course sections presentation.
- Enrollment ➜ Course registration button.
- Admin ➜ It has a dashboard to view information about students, lecturers, and courses.
- Notifications ➜  New assignment added and your quiz result is ready.

## ✏️ Installation Steps
1. Clone the Repository
git clone https://github.com/khaled057/EduTech.git
cd EduTech

3. Install Backend Dependencies
cd backend
npm install

4. Configure Environment Variables
Create a .env file inside the backend folder and add the required environment variables.

5. Run the Backend
From the backend folder:
npm run dev

6. Install Frontend Dependencies
Open a new terminal and navigate to the frontend folder:
cd frontend
npm install

7. Run the Frontend
npm run dev
Open the frontend URL in your browser and make sure the frontend is connected to the running backend API.

## ▶️ How to Run Backend and Frontend
### Run the Backend

Open a terminal and navigate to the backend folder:
cd backend
Start the backend server:
npm run dev

### Run the Frontend

Open another terminal and navigate to the frontend folder:
cd frontend
Start the React development server:
npm run dev
