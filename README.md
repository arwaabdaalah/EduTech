EduTech — Learning Platform

EduTech is a full-stack learning platform that allows students to discover courses, enroll, access learning content, complete assignments. Instructors can manage courses, assignments, and student submissions.

Tech Stack
Frontend: React, JavaScript
Backend: Node.js, Express
Database: MongoDB, Mongoose
Tools: Git, GitHub, Postman

Main Features
User authentication and role-based access
Course browsing, search, and filtering
Course enrollment
Learning content
Assignment submission 
Instructor/course management
Responsive and reusable UI
